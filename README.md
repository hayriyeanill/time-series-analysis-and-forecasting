# Time Series Analysis & Forecasting

This repository accompanies a blog series on **Time Series Analysis and Forecasting**.  
It contains the data processing, exploratory analysis, and forecasting workflows discussed throughout the series.

The repository evolves incrementally: after each blog article, the corresponding code, outputs, and visualizations are added or updated.

---

## 📘 Blog Series
 
The articles are listed below in the order they are published.

1. **Understanding Time Series Data**  
   *Understanding what time series data is, how it differs from other data types, and how to collect and prepare it.*


All figures, outputs, and code snippets shown in the articles are generated from this repository.

---

## 📂 Repository Structure

- ├── data/ # Raw and processed datasets
- ├── notebooks/ # Jupyter notebooks used in the blog series
- ├── src/ # Reusable processing and modeling code
- ├── README.md


## Python Version

This project is developed and tested using:

- **Python 3.10.9**

Using a different Python version may lead to minor differences in behavior or dependency compatibility.

---

## Environment Setup

It is recommended to run the notebooks in an isolated virtual environment.

```bash
python3.10.9 -m venv venv
source venv/bin/activate        # macOS / Linux
venv\Scripts\activate         # Windows

Install dependencies:
pip install -r requirements.txt
```
